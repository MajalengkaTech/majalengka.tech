# Majalengka Design System (MDS)

Majalengka Design System (MDS) adalah sistem desain terbuka yang dirancang khusus untuk memenuhi kebutuhan instansi pemerintahan, dinas daerah, dan inisiatif teknologi komunitas di Kabupaten Majalengka.

## Tujuan Utama
1. **Kredibel & Resmi**: Memberikan hierarki informasi yang kuat, tipografi bersih, dan palet warna yang memancarkan integritas serta keterbukaan pelayanan publik.
2. **Aksesibel**: Menjamin kepatuhan standar aksesibilitas internasional minimal **WCAG 2.1 AA** (rasio kontras warna tinggi, navigasi keyboard penuh, dan kompatibilitas pembaca layar).
3. **Multi-Platform & Framework-Agnostic**: Berbasis Design Tokens W3C/DTCG yang dapat di-export ke Tailwind CSS, UnoCSS, CSS Variables murni, maupun mobile apps.

## Konsep Terkait

- [Komponen UI Instansi](components.md) - Katalog komponen web esensial untuk portal publik.
- [Panduan Aksesibilitas](accessibility.md) - Checklist WCAG 2.1 AA dan tata cara pengujian.
