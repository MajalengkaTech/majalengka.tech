# Standar & Spesifikasi OKF

Majalengka Tech mengadopsi penuh **Open Knowledge Format (OKF)** yang digagas oleh Google Cloud Platform sebagai format standar penyimpanan pengetahuan.

## Mengapa OKF?
1. **Agent-Ready & Human-Friendly**: Dapat dibaca langsung oleh manusia via Markdown standar, dan diproses oleh LLM/agen AI tanpa SDK proprietary.
2. **Git-Centric**: Disimpan langsung sebagai file teks di dalam repositori Git, mendukung branching, pull request, code review, dan versioning.
3. **Vendor-Neutral**: Tidak terikat pada platform basis data tertentu.
