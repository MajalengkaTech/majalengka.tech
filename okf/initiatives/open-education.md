# Open Educational Resources (Coding & AI)

## Visi
Membangun talent pipeline engineer, data analyst, dan pengembang software handal dari kalangan pelajar SMP/SMA/SMK dan mahasiswa di Majalengka.

## Materi Kurikulum Terbuka
- **Dasar Pemrograman Web**: HTML, CSS modern, JavaScript, dan framework Vue / Nuxt.
- **Pengenalan IoT & Embedded Systems**: Pemrograman C++ / MicroPython dengan ESP32.
- **Pondasi Data Science & AI Terapan**: Analisis data menggunakan Python, Pandas, dan integrasi model AI generatif untuk menyelesaikan masalah lokal.
