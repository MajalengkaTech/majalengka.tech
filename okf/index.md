# Majalengka Tech Knowledge Base

## Struktur Pengetahuan

- [Majalengka Design System](design-system/index.md) - Desain sistem resmi untuk instansi dan aplikasi komunitas Majalengka.
- [Inisiatif & Proyek Unggulan](initiatives/index.md) - Inisiatif open-source bidang pertanian cerdas, pariwisata, UMKM, edukasi, dan data terbuka.
