# Spesifikasi Teknis OKF v0.2

## Anatomi Berkas Konsep
Setiap dokumen pengetahuan dalam bundle OKF menggunakan ekstensi `.md` dan diawali dengan YAML frontmatter:

```yaml
---
type: Concept | System | API | Dataset
title: Judul Konsep Jelas
description: Satu kalimat ringkasan tujuan dokumen.
resource: urn:nama:resource (opsional)
tags: [tag-1, tag-2]
status: active | draft | deprecated
verified: human:narr07
sources:
  - type: standard | manual
    name: Sumber Acuan
    url: https://...
---

# Isi Dokumen

Struktur konten dalam Markdown biasa yang mudah dibaca oleh manusia dan di-parse oleh agen AI.
```

## Sinyal Kepercayaan & Provenance
OKF v0.2 mengutamakan akuntabilitas pengetahuan yang dirawat oleh agen AI melalui:
- **`sources`**: Sumber data awal dari mana konsep diekstrak.
- **`verified`**: Tingkat verifikasi (apakah unverified, dikonfirmasi mesin, atau telah ditinjau manusia).
- **`status` & `stale_after`**: Sinyal kesegaran agar agen tidak menggunakan informasi kedaluwarsa.
