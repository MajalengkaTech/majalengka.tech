# Bundle OKF Majalengka Tech

Repositori `majalengka.tech` menyertakan bundle pengetahuan standar yang siap dikonsumsi langsung di folder `okf/`.

## Struktur Direktori Bundle
```
okf/
├── index.md                 # Entri utama katalog pengetahuan
├── log.md                   # Histori pembaruan bundle
├── design-system/           # Knowledge graph Majalengka Design System
│   ├── index.md
│   ├── tokens.md
│   ├── components.md
│   └── accessibility.md
├── initiatives/             # Knowledge graph 5 pilar inisiatif daerah
│   ├── index.md
│   ├── agritech-smart-farming.md
│   ├── tourism-open-platform.md
│   ├── umkm-digital-tools.md
│   ├── open-education.md
│   └── open-data-dashboard.md
└── standards/               # Dokumentasi spesifikasi format
    ├── index.md
    └── okf-v02-specification.md
```

## Cara Penggunaan oleh Agen AI
Agen AI dapat langsung membaca file di dalam direktori `okf/` sebagai *context ground truth* tanpa perlu melakukan query database yang rumit atau parsing format biner.
