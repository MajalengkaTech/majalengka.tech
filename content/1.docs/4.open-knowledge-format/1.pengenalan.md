# Open Knowledge Format (OKF)

**Open Knowledge Format (OKF)** adalah spesifikasi terbuka dan netral-vendor yang diinisiasi oleh Google Cloud Platform untuk merepresentasikan pengetahuan organisasi, metadata aset data, konteks arsitektur, dan wawasan terkurasi.

## Mengapa OKF Dibutuhkan?
Di era agen AI otonom, sistem metadata lama seringkali terkunci dalam basis data proprietary yang rumit. OKF menyelesaikan masalah ini dengan pendekatan:
- **Plain Markdown + YAML Frontmatter**: Dokumen teks biasa yang dapat langsung dibaca oleh manusia via editor teks mana pun dan dapat dimasukkan ke dalam *context window* LLM tanpa SDK proprietary.
- **Git-Centric**: Pengetahuan dapat dikelola dengan pull request, git blame, dan commit diff layaknya kode sumber software.
- **Interoperabilitas Tanpa Kunci Vendor**: Tidak tergantung pada database cloud tertentu; cukup disimpan dalam sebuah folder atau arsip git.
