## Memulai Cepat

Kamu bisa langsung menyalin (*clone*) repository proyek dan menjalankannya secara lokal menggunakan **Bun** atau Node.js:

```bash [Terminal]
# Salin repository
git clone https://github.com/MajalengkaTech/majalengka.tech.git

# Masuk ke direktori proyek
cd majalengka.tech

# Pasang dependensi
bun install

# Jalankan server pengembangan
bun dev
```

Buka peramban kamu di [http://localhost:3000](http://localhost:3000). Website sudah aktif dan siap kamu jelajahi atau kembangkan!

## Kebutuhan Sistem

- **Bun** (disarankan, versi 1.1+) atau Node.js v20+
- **Git** untuk mengelola versi kode
- Akun **GitHub** jika ingin mengirimkan kontribusi atau perbaikan bug
