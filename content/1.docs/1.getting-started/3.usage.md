## Menulis & Mengedit Dokumentasi

Semua artikel dokumentasi disimpan dalam format Markdown (`.md`) di dalam folder [`content/1.docs/`](https://github.com/MajalengkaTech/majalengka.tech/tree/main/content/1.docs). Begitu kamu mengedit atau menambah file di folder tersebut, navigasi di samping dan pencarian situs akan otomatis diperbarui.

::tip
Punya ide perbaikan tulisan atau menemukan kesalahan ketik? Kamu bisa langsung klik tombol edit di GitHub dan kirim Pull Request!
::

## Menambahkan Karya ke Showcase

Jika kamu developer atau pegiat teknologi yang sedang membangun proyek di Majalengka:

1. Buat akun di halaman [Daftar Developer](/signup).
2. Masuk ke [Dashboard Proyek](/dashboard/projects).
3. Klik **Tambah Proyek** dan isi judul, deskripsi singkat, link repo, demo web, serta unggah foto tangkapan layar.
4. Proyekmu akan langsung tampil di halaman [Showcase Proyek](/projek) agar bisa dicoba oleh teman-teman lainnya!
