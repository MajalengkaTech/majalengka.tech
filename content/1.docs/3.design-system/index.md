# Majalengka Design System (MDS)

Majalengka Design System adalah panduan identitas visual dan pustaka komponen terbuka yang dirancang khusus untuk portal dinas pemerintahan dan aplikasi komunitas di Kabupaten Majalengka.

## Bagian Utama
- [🏛️ Prinsip Desain & IDDS](/docs/design-system/prinsip) - Nilai dasar kredibilitas instansi dan keselarasan dengan INA Digital Design System.
- [🎨 Design Tokens](/docs/design-system/tokens) - Palet warna hijau lereng Ciremai, tipografi Inter, dan skala spasi modular.
- [♿ Aksesibilitas WCAG 2.1 AA](/docs/design-system/aksesibilitas) - Standar aksesibilitas internasional untuk menjamin inklusivitas pelayanan publik.
