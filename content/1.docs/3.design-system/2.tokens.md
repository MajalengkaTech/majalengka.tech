# Design Tokens

Token desain adalah representasi data dari keputusan visual antarmuka:

## Palet Warna
- **Primary Emerald (`#059669`)**: Menggambarkan nuansa alam pegunungan Ciremai, perkebunan teh, dan harapan kesuburan tanah Majalengka.
- **Deep Emerald (`#047857`)**: Aksen kontras untuk tombol aktif dan interaksi hover.
- **Teal Aksen (`#0d9488`)**: Aksen pendukung untuk kartu inovasi dan badge status.
- **Slate Neutral (`#0f172a` & `#f8fafc`)**: Kontras tinggi untuk kenyamanan membaca dokumen resmi.

## Tipografi
- **Huruf Primer**: `Inter`, font sans-serif dengan legibilitas superior pada layar perangkat bergerak.
- **Heading**: Bobot 600 (Semi-bold) & 700 (Bold).
- **Body Text**: Ukuran 16px (1rem), rasio jarak baris 1.6.

## Ekspor Tokens
Dikelola dengan **Style Dictionary** untuk menghasilkan variabel CSS dan preset Tailwind / UnoCSS secara otomatis.
