# Aksesibilitas Web (WCAG 2.1 AA)

## Checklist Standar Kepatuhan
1. **Rasio Kontras Warna**:
   - Teks biasa minimal rasio `4.5:1` terhadap latar belakang.
   - Teks besar (>18pt atau bold 14pt) minimal `3:1`.
2. **Navigasi Keyboard Penuh**:
   - Semua tombol, menu accordion, formulir, dan dialog modal dapat dibuka dan ditutup menggunakan tombol `Tab`, `Enter`, `Space`, dan `Escape`.
   - Ring fokus (`focus-visible`) wajib terlihat jelas (`ring-2 ring-emerald-500`).
3. **Deskripsi Gambar & Ikon**:
   - Setiap elemen grafis memiliki `alt` text bermakna. Ikon dekoratif ditandai dengan `aria-hidden="true"`.
