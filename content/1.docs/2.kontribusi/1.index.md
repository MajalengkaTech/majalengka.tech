Kode situs ini terbuka dengan lisensi MIT di [github.com/majalengkatech/majalengka.tech](https://github.com/majalengkatech/majalengka.tech). Laporan bug, usulan, dan pull request diterima lewat repositori itu.

## Teknologi yang dipakai

| Bagian | Teknologi |
|---|---|
| Framework | Nuxt 4 |
| Komponen UI | Nuxt UI 4 dengan Tailwind CSS 4 |
| Konten (panduan, changelog) | Nuxt Content 3 |
| Database dan penyimpanan file | NuxtHub dengan Cloudflare D1 dan R2, lewat Drizzle ORM |
| Login | Better Auth (email dan password, GitHub, Google) |
| Package manager | Bun |

## Menjalankan di komputermu

1. Clone repositori, lalu pasang dependensi:
   ```bash [Terminal]
   bun install
   ```
2. Salin `.env.example` menjadi `.env`, lalu isi `NUXT_BETTER_AUTH_SECRET` dengan teks acak minimal 32 karakter. Isian OAuth GitHub dan Google boleh dikosongkan kalau kamu cukup login dengan email.
3. Jalankan server pengembangan:
   ```bash [Terminal]
   bun run dev
   ```
   Database SQLite lokal dibuat di `.data/`, dan migrasi dijalankan otomatis.

::note
Unggah gambar belum bisa dicoba di komputer lokal, karena penyimpanan Cloudflare R2 tidak tersedia di luar Cloudflare. Untuk mencoba form karya, tempel link gambar `https://`.
::

## Sebelum mengirim pull request

```bash [Terminal]
bun run lint
bun run typecheck
```

Kalau perubahanmu besar, coba juga build produksi. Build membutuhkan memori lebih besar dari bawaan Node:

```bash [Terminal]
NODE_OPTIONS=--max-old-space-size=8192 bun run build
```

## Mengubah struktur database

Ubah `server/db/schema.ts`, lalu buat file migrasi dengan:

```bash [Terminal]
bunx nuxt-db generate
```

Jangan menulis atau mengubah tabel lewat skrip manual. Migrasi di server produksi dijalankan oleh pengelola setelah pull request digabungkan.
