Kode situs ini terbuka dengan lisensi MIT di [github.com/majalengkatech/majalengka.tech](https://github.com/majalengkatech/majalengka.tech). Kirim laporan bug, usulan, atau pull request lewat repositori itu.

## Teknologi yang dipakai

| Bagian | Teknologi |
|---|---|
| Framework | Nuxt 4 |
| Komponen UI | Nuxt UI 4 dengan Tailwind CSS 4 |
| Konten (panduan, changelog) | Nuxt Content 3 |
| Database | NuxtHub dengan SQLite, lewat Drizzle ORM |
| Penyimpanan gambar | Cloudinary |
| Login | Better Auth (email dan kata sandi, GitHub, Google) |
| Package manager | Bun |

## Menjalankan di komputermu

1. Clone repositori, lalu pasang dependensi:
   ```bash [Terminal]
   bun install
   ```
2. Salin `.env.example` menjadi `.env`, lalu isi `NUXT_BETTER_AUTH_SECRET` dengan teks acak minimal 32 karakter. Kolom OAuth GitHub dan Google boleh kosong kalau kamu cukup masuk dengan email.
3. Jalankan server pengembangan:
   ```bash [Terminal]
   bun run dev
   ```
   Server pengembangan membuat database SQLite di `.data/` dan menjalankan migrasinya sendiri.

::note
Unggah gambar bisa dicoba di komputer lokal. Kalau kolom Cloudinary di `.env` kosong, gambar tersimpan di folder `.data/blob`.
::

## Sebelum mengirim pull request

```bash [Terminal]
bun run lint
bun run typecheck
```

Kalau perubahanmu besar, coba juga build produksi. Build membutuhkan memori lebih besar dari bawaan Node:

```bash [Terminal]
NODE_OPTIONS=--max-old-space-size=8192 bun run build
```

## Mengubah struktur database

Ubah `server/db/schema.ts`, lalu buat file migrasi dengan:

```bash [Terminal]
bunx nuxt-db generate
```

Jangan menulis atau mengubah tabel lewat skrip manual. Setelah pull request digabungkan, pengelola situs menjalankan migrasinya di server produksi.
