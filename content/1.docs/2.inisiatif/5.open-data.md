# Open Data & Visualisasi Publik

## Misi
Menyajikan data statistik komoditas pertanian, data pariwisata, dan cuaca mikro dalam format terbuka yang siap dianalisis dan divisualisasikan oleh peneliti, mahasiswa, serta publik.

## Format Distribusi
- **API Terbuka**: Format respons JSON standar.
- **Tabel Siap Olah**: Format CSV dan Parquet.
- **Knowledge Bundle**: Representasi terstruktur menggunakan Google Cloud Open Knowledge Format (OKF) untuk konsumsi agen AI.
