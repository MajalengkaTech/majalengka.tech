Versi **v0.2.0** menandai dimulainya kapabilitas *full-stack* interaktif pada platform Majalengka Tech:

### 🌟 Fitur Utama:
- **Autentikasi Multi-Provider**: Dukungan login instan menggunakan akun GitHub dan Google melalui `nuxt-auth-utils` tanpa password rumit.
- **Serverless Edge Database**: Penyimpanan data pengguna dan entitas platform berbasis SQLite di jaringan edge global menggunakan Cloudflare D1.
- **ORM Terstruktur & Tipe Aman**: Pemodelan basis data menggunakan Drizzle ORM dengan skema relasi pengguna dan projek yang siap berkembang.
- **Sesi Pengguna Terenkripsi**: Pengamanan cookie sesi dengan algoritma segel (*sealed cookies*) berkinerja tinggi di sisi server.
