Pembaruan v0.3.0 menghadirkan fondasi data relasional dan sistem login terpadu bagi kontributor platform Majalengka Tech.

## Sorotan Rilis

- **Autentikasi Modern dengan Better Auth**: Integrasi `@nuxtjs/better-auth` dan `better-auth` dengan dukungan login sosial satu klik melalui GitHub OAuth dan Google OAuth.
- **Database Relasional Cloudflare D1**: Migrasi skema SQLite D1 untuk tabel pengguna, sesi, akun OAuth, serta relasi foreign key pada tabel proyek (`user_id REFERENCES user(id)`).
- **Dashboard Pengembang**: Antarmuka interaktif pada `/dashboard` yang memungkinkan pengguna mengelola proyek milik mereka, memperbarui informasi profil, dan mengunggah thumbnail.
- **Konsol Administrasi & Moderasi**: Halaman `/kelola` terproteksi untuk administrator dalam memoderasi direktori proyek dan data akun.
- **Siklus Hidup Aset R2 Bersih**: Penambahan logika penghapusan cascading saat proyek dihapus atau thumbnail diperbarui agar tidak menyisakan file yatim di Cloudflare R2.
