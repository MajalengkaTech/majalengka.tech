Rilis ini memberi Majalengka Tech sistem login dan database, jadi setiap kreator bisa mengelola proyeknya sendiri.

## Yang ada di rilis ini

- **Login dengan Better Auth.** Kamu bisa masuk dengan satu klik lewat akun GitHub atau Google.
- **Database Cloudflare D1.** Tabel pengguna, sesi, akun login, dan proyek tersimpan di D1. Setiap proyek terhubung ke pemiliknya (`user_id REFERENCES user(id)`).
- **Dashboard.** Di `/dashboard` kamu bisa mengelola proyekmu, memperbarui profil, dan mengunggah thumbnail.
- **Halaman Kelola untuk pengelola situs.** `/kelola` hanya bisa dibuka pengelola situs, untuk merapikan daftar proyek dan akun.
- **File di R2 ikut dibersihkan.** Saat proyek dihapus atau thumbnail diganti, file lamanya ikut terhapus, jadi tidak ada gambar yatim yang menumpuk di Cloudflare R2.
