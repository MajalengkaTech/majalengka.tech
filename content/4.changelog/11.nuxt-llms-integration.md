Kami sangat antusias mengumumkan rilis pembaruan ekosistem platform **Majalengka Tech**! Pembaruan ini fokus pada interoperabilitas kecerdasan buatan (AI & LLMs), keandalan autentikasi di edge runtime, serta manajemen aset media yang lebih efisien.

## 🤖 Integrasi Nuxt LLMs (`/llms.txt`)

Platform Majalengka Tech kini secara otomatis mengekspor konten dokumentasi dan artikel teknis dalam format standar AI-ready menggunakan modul `nuxt-llms`:

- **Standardisasi `/llms.txt`**: Agen AI, asisten koding, dan LLM kini dapat membaca peta konten, panduan komunitas, dan direktori riset secara terstruktur langsung dari endpoint `/llms.txt`.
- **Raw Markdown Endpoints (`/raw/*.md`)**: Menyediakan konten murni berbobot rendah tanpa overhead rendering HTML, menghemat token context window bagi LLM eksternal.
- **Auto Section Filtering**: Mengelompokkan koleksi dokumentasi teknis dan artikel riset komunitas secara terpisah dan terkurasi.

## 🔐 Pembaruan Autentikasi Better Auth di Cloudflare Workers

Kami menyempurnakan integrasi `@nuxtjs/better-auth` untuk runtime edge Cloudflare Workers:

- **Dukungan Runtime Config Penuh**: Sinkronisasi secret key dan kredensial OAuth (GitHub & Google) melalui Nuxt `runtimeConfig`, menjamin keandalan login sosial di lingkungan serverless.
- **Penyelarasan Skema D1**: Migrasi skema database SQLite D1 untuk tabel sesi, akun, verifikasi, dan relasi multi-user dengan foreign key terstandarisasi.
- **Hak Akses Administrator Terpadu**: Panel kelola dan API kini memberikan kontrol moderasi menyeluruh bagi super administrator terhadap proyek dan pengguna komunitas.

## 📦 Pembersihan Otomatis Cloudflare R2 Blob

- **Siklus Hidup Aset Bersih**: Setiap penghapusan atau pembaruan proyek yang memiliki thumbnail otomatis memicu pembersihan file lama dari bucket Cloudflare R2 (`hub:blob`), mencegah penumpukan file yatim (*orphaned files*).
