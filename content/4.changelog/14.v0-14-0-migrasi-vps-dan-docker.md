Rilis ini membawa perubahan arsitektur besar di sisi infrastruktur deployment portal Majalengka Tech.

## Migrasi ke VPS & Docker Container

- **Runtime Mandiri**: Aplikasi kini berjalan di atas container Docker dengan runtime Node.js 22 LTS, menggantikan runtime serverless untuk menghilangkan batasan waktu eksekusi CPU.
- **Nuxt Nitro Preset**: Preset Nitro beralih ke `node-server` dengan manajemen container via `docker-compose`.
- **Database & Penyimpanan Persisten**: Database SQLite dan aset upload tersimpan aman menggunakan volume mount disk server.

## Dukungan Cloudinary

- Konfigurasi `@nuxt/image` kini mendukung provider Cloudinary untuk optimasi gambar otomatis (`f_auto`, `q_auto`), dengan fallback cerdas ke pemroses lokal (`ipx`) saat berjalan secara mandiri.
