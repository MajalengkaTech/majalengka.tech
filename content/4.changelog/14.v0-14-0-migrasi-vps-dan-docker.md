Rilis ini sebagian besar terjadi di balik layar. Situsnya tetap sama, tetapi tempatnya berjalan sudah pindah.

## Pindah ke server sendiri

- Majalengka Tech sekarang berjalan di server sendiri, bukan lagi di layanan serverless dengan batas waktu proses per kunjungan. Halaman yang berat tidak lagi gagal karena batas itu.
- Semua akun, proyek, apresiasi, dan komentar ikut dipindahkan. Kamu tidak perlu mendaftar ulang.
- Database dicadangkan setiap hari.

## Gambar proyek

- Gambar sampul, galeri, dan foto profil yang kamu unggah kini disimpan di Cloudinary. Gambar lama sudah ikut dipindahkan.
- Ukuran dan format gambar disesuaikan dengan layar dan browser kamu, jadi halaman proyek terbuka lebih ringan.
- Gambar yang kamu unggah hanya bisa terhapus lewat proyek atau akunmu sendiri.

## Kartu kreator untuk README GitHub

- Di halaman profil, tombol bagikan kini menyediakan kode Markdown dan HTML untuk memasang kartu kreatormu di README profil GitHub atau website.
- Kartunya selalu menampilkan jumlah proyek dan apresiasi terbaru, dan bisa juga diunduh sebagai PNG.
- Pratinjau tautan profil di X (Twitter) kini menampilkan kartu itu.
